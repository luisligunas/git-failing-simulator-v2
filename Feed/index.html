FeedAt least one of every element and every configuration, in one scroll. A real week would run four or five sections, not eighteen.

1 · Cards

Marketing placements. No byline, no timestamp, nothing to heart — they are slots, not messages. Three of them. Feature and Notice hold one thing; Collection holds several and defines its own item shape — there is no generic container you can drop any card into, so a Feature cannot go inside a Collection, and a Collection never links out to a bigger one.

Feature card — one card, three layouts

The same record rendered three ways. Identical image, tag chip, timing chip, headline, sub-line and CTA. Every field works in every layout — only the arrangement changes, so the editor switches layout with a dropdown and nothing is re-authored or lost.
